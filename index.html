Texto

En el desarrollo web es fundamental aplicar énfasis visual y marcar texto importante. Podemos indicar notas con letra pequeña, descartar elementos con texto tachado, referenciar fuentes mediante una cita bibliográfica, e insertar citas cortas como el código limpio habla por sí mismo. Además, podemos definir conceptos complejos usando semántica web, estructurar siglas como HTML o registrar fechas precisas como 10 de octubre de 2026.

Al escribir y ejecutar el script de Python print(f"Hola {nombre}"), asignamos un valor de entrada a la variable nombre, comprobamos que la consola devuelva la respuesta exacta Hola Jaime y guardamos el archivo de código pulsando las teclas Ctrl + S.

También disponemos de formato tipográfico básico como subíndice H2O, superíndice X2, texto en itálica, en negrita, subrayado, texto resaltado, contenedores en línea con span, un salto de línea formal
y un punto de ruptura opcional de palabra conpunto.
